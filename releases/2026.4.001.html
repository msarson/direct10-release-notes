Direct10 2026.4.001
Release date: October 26, 2026
2 Fixed

What you should know about 2026.4.001

2026.4.001 corrects an invoice printing problem where a charge description that begins with a space was printed in the wrong place and cut short, with part of the invoice form itself showing through in its place. It also corrects the way sales agent and driver numbers are printed on invoice and statement forms.

Accounts Receivable

All changes in 2026.4.001

Accounts Receivable

  • Charge descriptions beginning with a space printed in the wrong place and cut short Fixed

    Applies to: customers printing or emailing invoices where a charge description begins with a space. This includes descriptions typed with leading spaces to indent a continuation line, and descriptions that come from a billing code whose description begins with a space.

    When a charge description began with a space, the invoice form treated it as a number rather than as text. The description was shortened to its last few characters and pushed to the right-hand end of the description column, and part of the invoice form's own layout was left showing where the description should have started. Descriptions are now printed as text in every case: they begin at the left of the description column, keep any spacing you have typed, and use the full width the column allows. Charge amounts, units, rates and other figures continue to line up on the right as before.

  • Sales agent and driver numbers printed using a date format Fixed

    Applies to: any site whose invoice or statement form shows the sales agent number or driver number. Storage Manager forms are affected as well as Accounts Receivable forms.

    The sales agent number and driver number were formatted using a date layout instead of a number layout, so they could print incorrectly on forms that include them. Both now print as plain numbers. If your forms show either of these fields, the printed result will change with this release.
