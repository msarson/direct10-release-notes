Commercial Records Storage

All changes in 2026.3.005

Commercial Records Storage

  • Pro-Forma Monthly Billing failing with a database error Fixed

    Applies to: Commercial Records Storage customers running Pro-Forma or Monthly Storage Billing.

    Calculating Pro-Forma or Monthly Storage Billing could fail with a database error for customers with containers on file. This is now corrected.

  • Printing custom-format invoices failing with a coding error Fixed

    Applies to: Commercial Records Storage customers using a custom invoice format.

    Printing invoices using a custom invoice format could fail with a "Coding Error, No module set" message, preventing the invoice PDF from being created or emailed. This is now corrected.

  • Pro-Forma Monthly Billing window showed the wrong title Fixed

    The Pro-Forma Monthly Billing window displayed "Calculate Monthly Storage Billing" instead of reflecting Pro-Forma. It now shows the correct title.
