Direct10 2026.4.004
In development
3 Fixed 2 Improved

What you should know about 2026.4.004

2026.4.004 fixes the MoverBiz Load Board calendar, which could show no Work Tickets for a day or week after a ticket's date or time had been changed. It also warns you when a new Work Ticket time would book an assigned resource at the same time as another Work Ticket, and makes MoverBiz work properly on screens where Windows display scaling is set above 100%.

Dispatch

All changes in 2026.4.004

Dispatch

  • Load Board calendar showed no Work Tickets for a busy day or week Fixed

    Applies to: anyone using the MoverBiz Load Board calendar in the Day or Week view.

    After a Work Ticket's date or time had been changed, the Day and Week views could show no Work Tickets at all for that day, or for the whole week, while the Work Tickets list and the Month view still showed them. No Work Tickets were lost. Every Work Ticket now shows, side by side where they overlap, so there is no longer any need to move a ticket by a minute to bring the day back.

  • Warning when a new Work Ticket time double-books a resource Improved

    Applies to: anyone changing Work Ticket dates on the MoverBiz Load Board.

    When you save a new Started time in the Load Board's Dates pane, and one of the Work Ticket's assigned crew members or vehicles is already on another Work Ticket at that exact time, a Resource Conflict message now lists them. Select Yes to save the new time anyway, or No to go back and change it.

  • Load Board assignments could not be made when display scaling was above 100% Fixed

    Applies to: anyone whose Windows display scaling is set to 125%, 150% or more, which is common on laptops and high-resolution monitors.

    In the Load Board's Assignments pane, the checkboxes used to assign crew members and vehicles were not shown, and clicking where they should be did nothing, so nobody could be assigned from the Load Board. The rows in MoverBiz lists were too short at those settings. They now grow with your display scaling, so the checkboxes show and the lists are easier to read.

  • Parts of the Load Board and Trip Planner cut off or overlapping when display scaling was above 100% Fixed

    Applies to: anyone whose Windows display scaling is set to 125%, 150% or more.

    At higher display scaling the Load Board's filter calendar lost its month arrows and the first and last days of the week, the calendar's times were cut off, and the filter labels on the Load Board, Trip Planner and report filters were hidden behind their drop-downs. The Trip Planner's Assign Driver rows could also overlap. These now all fit at any display scaling. If you had widened the filter panel while using a display scaling above 100%, it may open wider once; drag it back to the width you want and it will stay.

  • Sharper report windows when display scaling is above 100% Improved

    Applies to: anyone whose Windows display scaling is set above 100%.

    MoverBiz report windows, and the Tariff Interface, were stretched by Windows and looked slightly blurry at display scaling above 100%. They are now drawn at your display's own scale, so text and buttons are sharp.
