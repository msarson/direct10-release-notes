Direct10 2026.4.003
Release date: November 24, 2026
1 Fixed

What you should know about 2026.4.003

2026.4.003 corrects a problem in 2026.4.002 that stopped the Recent Activity in the Job Master File report from opening.

Dispatch

All changes in 2026.4.003

Dispatch

  • Recent Activity report closed with an error instead of opening Fixed

    Applies to: anyone on 2026.4.002 who opens the Recent Activity in the Job Master File report.

    In 2026.4.002 the Recent Activity in the Job Master File report showed the message “Conversion from type 'AAUserName' to type 'String' is not valid” and closed before it could be used. It now opens as it did before, with Entered By set to Include All Users, or to the Atlas Connect Service when the report is opened from Atlas Connect.
