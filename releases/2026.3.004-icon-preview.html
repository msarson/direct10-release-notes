2026.3.004 Coming Soon

Here's what's fixed and improved in this release.

Payroll

  • New

    Mark employees as not eligible for FLSA overtime

    A new checkbox — FLSA Overtime Eligible — has been added to the Employee Master File, Payroll tab. Federal law only requires overtime premium (W-2 Code TT) to be paid on hours actually covered by FLSA Section 7, which doesn't apply to salaried, administrative, highly-skilled, or owner employees. Unchecking this box for an employee excludes their overtime pay from W-2 Code TT reporting. Every existing employee defaults to eligible, so nothing changes for anyone unless you specifically mark them exempt.

  • Improved

    More accurate W-2 overtime reporting for split paychecks

    If an employee's overtime hours were split across a paycheck — some hours paid at regular rate, the rest at overtime — W-2 Code TT now correctly includes the premium for all of those overtime hours, not just the portion that was entered directly as an overtime line.

  • Fixed

    Military Variables not printing on Paperwork formats

    Military Variables 1D and 1E are now printing correctly on Paperwork formats again.

Accounts Payable

  • Fixed

    A check could be voided twice

    Voiding an already-voided check is no longer possible.

  • Fixed

    Print Checks posting to the wrong GL account

    In certain situations, Print Checks could post to an incorrect GL account. This is now corrected.

  • Improved

    Clearer guidance on the Reclassify as Manual Check screen

    Added on-screen text explaining what this action does, so it's clearer what to expect before confirming.

Dispatch

  • Fixed

    Invoices created with a blank invoice number

    Invoices transferred from Dispatch billing could occasionally end up with no invoice number assigned, which meant they wouldn't appear on the Invoices tab in Accounts Receivable even though the billing itself had gone through correctly. A valid invoice number is now always assigned.

  • Fixed

    Crash opening Shipment Management

    Opening Shipment Management from Dispatch could crash the application entirely, requiring a restart and re-adding shortcuts. This is now resolved.

  • Improved

    More reliable Shipment Management job list

    Jobs that had already been resolved could keep lingering in the "needs attention" list. Resolved jobs now drop off the list as expected, and each remaining job shows one clear, accurate reason it still needs review.

General Ledger

  • Fixed

    New budget years missing Expense accounts

    Preparing a new Budget Year (Actual basis) was skipping Expense accounts entirely, so a newly created budget had no expense figures at all — only Revenue accounts came through. Expense accounts are now included alongside Revenue accounts.

Storage Manager

  • Fixed

    Quarterly billing running a month late

    Storage lots set to bill quarterly with a Starting Month of 2, 5, 8, or 11 using Behind accrual were billing a month later than they should have — and in one case, not billing at all. These lots now bill in the correct month.

Van Line Statement Download

  • Fixed

    Statement preview sort order getting stuck

    Once you sorted a column in the statement preview, it would stay sorted that way permanently — even clicking Reset couldn't bring back the original order. The preview now always opens in the original download order, regardless of any sorting from a previous session.

Reporting

  • Fixed

    Generated PDFs locked against editing

    PDF reports generated from Save As, Email, or automatic PDF creation were coming out encrypted with editing, copying, and form-filling disabled — even when no password was set. PDFs now generate fully open and editable unless you specifically enter a password when saving.

  • Fixed

    Commissions report filter returning no results

    The Agent Master report's posting-type filter wasn't working — filtering to a specific posting type silently returned no records. This is now corrected.

General

  • Fixed

    Ctrl+Tab not switching tabs

    Ctrl+Tab wasn't switching between tabs on certain windows. Keyboard tab-switching now works consistently throughout the application.

  • Improved

    Clear message when your database needs updating

    If your database is behind the version Direct10 expects, the application would previously fail to start with no explanation. It now shows a clear message telling you the database needs to be updated, instead of leaving you guessing.

  • Fixed

    Connection failures on newer database drivers

    Sites using newer ODBC database drivers combined with a longer database name could fail to connect at all, because the connection string field was too short to hold the full driver and database name together. This is now resolved.

  • Improved

    Ongoing data-handling and logging hardening

    Continued behind-the-scenes work to reduce what sensitive information gets written to diagnostic logs. No action needed on your part.

  • Improved

    Updated remote-support link

    The Help menu's remote-support link now points to our current support tool, replacing the retired link that no longer worked.
