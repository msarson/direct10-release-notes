What you should know about 2026.4.002

2026.4.002 corrects a problem in the Database Install, Clone and Upgrade Wizard where a new data set could not be saved on a system that did not yet have any data sets, such as a new installation.

General

All changes in 2026.4.002

General

  • New data set could not be saved when no data sets existed yet Fixed

    Applies to: anyone adding the first data set in the Database Install, Clone and Upgrade Wizard (SQLInstallAndUpgrade), for example on a new installation or a new server.

    When no data sets existed yet, the Data Set ID on the new data set form was left blank and could not be entered, so pressing OK refused to save because the ID was missing. The first data set is now given ID 1 automatically. Adding a second data set in the same session also now gets the next ID, instead of reusing the one just created. Systems that already have data sets are not affected.
