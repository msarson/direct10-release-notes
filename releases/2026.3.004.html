2026.3.004 Coming Soon

Here's what's fixed and improved in this release.

Payroll

  • Fixed

    Some overtime pay types were calculating at half the correct premium rate.

  • Fixed

    Overtime hours that carried over onto a later paycheck weren't always being reported correctly on the W-2.

  • Fixed

    Military variables weren't printing on certain paperwork formats.

  • Improved

    Added an option to mark an employee as not eligible for FLSA overtime, so W-2 overtime reporting is accurate for salaried and other exempt staff.

  • Improved

    Overtime type is now shown on historical paycheck detail screens.

Accounts Payable

  • Fixed

    A check could be voided a second time when it shouldn't have been possible.

  • Fixed

    Print Checks could post to the wrong GL account in certain situations.

  • Improved

    Clearer guidance text added to the Reclassify as Manual Check screen.

Accounts Receivable & Dispatch

  • Fixed

    Invoices could occasionally be created with a blank invoice number and not show up on the Invoices tab.

  • Fixed

    A crash when opening Shipment Management from Dispatch.

  • Fixed

    Shipment Management could show outdated or incorrect status information for some jobs.

General Ledger

  • Fixed

    Preparing a new budget year skipped Expense accounts, so new budgets had no expense figures.

Storage Manager

  • Fixed

    Certain storage lots were billing in the wrong month under quarterly billing.

Van Line Statement Download

  • Fixed

    The statement preview's sort order could get stuck after sorting a column, and wouldn't reset back to the original order.

Reporting

  • Fixed

    Generated PDF reports came out locked/encrypted, preventing editing in Adobe, even with no password set.

  • Fixed

    A commissions report filter wasn't returning results for a specific posting type.

General

  • Fixed

    Ctrl+Tab didn't switch tabs on certain windows.

  • Fixed

    The application could fail to start with no explanation if your database needed an update — a clear message is now shown instead.

  • Fixed

    Connection issues on sites using newer database drivers with longer names.

  • Improved

    Further hardening of behind-the-scenes data handling and logging.

  • Improved

    Updated the Help menu's remote-support link.
